# راه‌اندازی StudyOS روی GitHub Pages

این بسته برای انتشار StudyOS به‌صورت یک سایت استاتیک/PWA در GitHub Pages آماده شده است. مسیرهای فایل‌ها و Service Worker برای آدرس پروژه‌ای (`USERNAME.github.io/studyos/`) تنظیم شده‌اند.

## قبل از شروع
- GitHub Pages در پلن رایگان برای انتشار باید از مخزن عمومی استفاده کند.
- خود سایت و کدهایش عمومی و قابل مشاهده خواهند بود. اطلاعات مطالعه در این نسخه در حافظه محلی مرورگر ذخیره می‌شود و به مخزن GitHub ارسال نمی‌شود.
- این نسخه بک‌اند ندارد؛ اتصال واقعی Gemini/GPT، همگام‌سازی بین آیفون و ویندوز و ورود با رمز در آن فعال نیست. دستیار محلی و گزارش‌گیری محلی کار می‌کنند.
- اگر دامنه `github.io` نیز در شبکه شما مسدود باشد، این روش هم از همان شبکه باز نخواهد شد. قبل از انتقال کامل، آدرس نمونه را روی دستگاه خود آزمایش کنید.

## انتشار
1. وارد https://github.com شوید و وارد حساب خود شوید.
2. از علامت `+` بالا، `New repository` را انتخاب کنید.
3. نام مخزن را دقیقاً `studyos` بگذارید.
4. گزینه `Public` را انتخاب کنید و مخزن را بسازید.
5. فایل ZIP را روی کامپیوتر Extract کنید.
6. داخل مخزن `studyos`، `Add file` سپس `Upload files` را بزنید.
7. **محتویات داخل پوشه استخراج‌شده** را انتخاب و آپلود کنید؛ خود فایل ZIP را آپلود نکنید. فایل `index.html` باید مستقیماً در ریشه مخزن دیده شود، نه داخل یک پوشه دیگر.
8. پایین صفحه `Commit changes` را بزنید.
9. وارد `Settings` سپس `Pages` شوید.
10. در `Build and deployment`، گزینه `Deploy from a branch` را انتخاب کنید.
11. Branch را روی `main` و Folder را روی `/(root)` بگذارید و `Save` را بزنید.
12. پس از پایان انتشار، آدرس سایت این شکل خواهد بود:

   `https://USERNAME.github.io/studyos/`

   به‌جای `USERNAME` نام کاربری GitHub خودتان را بگذارید. وضعیت انتشار را از بخش `Actions` یا `Settings > Pages` ببینید.

## نصب روی آیفون
1. آدرس سایت را در Safari باز کنید.
2. دکمه Share را بزنید.
3. `Add to Home Screen` را انتخاب کنید.
4. نام StudyOS را تأیید و `Add` را بزنید.

## نصب روی Windows
در Chrome یا Edge، منوی مرورگر را باز کنید و گزینه `Install page as app` یا `Apps > Install this site as an app` را انتخاب کنید.

## نکته درباره داده‌ها
داده‌های ذخیره‌شده در مرورگر هر دستگاه جدا هستند. آیفون و ویندوز خودکار با هم همگام نمی‌شوند. از داخل StudyOS به‌طور منظم نسخه پشتیبان JSON بگیرید و آن را در جای امن نگه دارید. فایل پشتیبان را در مخزن عمومی GitHub آپلود نکنید.

## نسخه موبایل
این بسته شامل اصلاح ریسپانسیو مخصوص آیفون است. منوی کناری در موبایل به‌صورت کشویی باز می‌شود و از اسکرول افقی کل صفحه جلوگیری شده است. جدول گزارش‌ها در صورت نیاز فقط در کادر خودش اسکرول افقی دارد. پس از آپلود نسخه جدید، یک‌بار صفحه را در Safari تازه‌سازی کن؛ نام کش Service Worker هم تغییر کرده تا نسخه قدیمی به نسخه جدید به‌روزرسانی شود.
